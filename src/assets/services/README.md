# Hizmet fotoğrafları

Liste sayfasındaki şeritlerde kullanılan fotoğraflar. Dosya adı hizmetin
`services.ts`'teki `id`'siyle eşleşir; alt metin aynı dosyada dil başına durur.
Yeni hizmete fotoğraf eklemek için buraya `<id>.jpg` koymak yeterlidir
(`ServiceStrip.astro` içindeki eşleme tablosuna da import eklenir).

Kaynaklar — hepsi Pexels, ücretsiz ticari lisans, atıf gerekmez
(https://www.pexels.com/license/):

| `mobile.jpg` | https://www.pexels.com/photo/215367/ |

YouTube vb. görünen adaylar bu yüzden elendi).
